# Tidal Compass

Created and reviewed in live Blender and the separate native Badge Studio preview. The final working checkpoint is candidate03.

[Reference comparison](candidate03/review/comparison.png) | [All sides](candidate03/review/all_sides.png) | [Slow turn](candidate03/review/full_turn.mp4).

Reference traced smooth continuous pearl crescent and wave, separate silver edging and sixteen physical compass facets, matching sculpted rear. Distinctive thin frame preserves this reference instead of changing the approved shared twelve coin template.. Each front has a finished matching rear and continuous side walls. Existing badges and the production app are preserved.

The requested reference weathering and surface color are retained with reference appearance fill. Physical metal uses the measured native studio response, so live reflections and glints change during rotation. Any gemstone has independent closed convex geometry and the existing runtime optical shader, without photographed appearance textures. Emissive flame or atmospheric artwork remains distinct from gemstone optics.

Native front, early turn, both sides, back and full turn were visually checked, along with four times outline views and the reflection. ARKit USD validation and closed solid checks passed. 32844 triangles; 2.63 MB.

The deliberate reference texture is an exception to the generic smooth surface preference. The rendered highlights differ from a static illustration because the studio stays fixed while the object turns. The comparison records the actual current match.

The pearl and teal wave are opaque enamel relief with smooth normals and changing physical reflections, not transparent ray traced gemstones. Constrained Blender triangulation removes the earlier dark boundary teeth. Compass and frame vertical walls use a plain silver finish to avoid stretched front imagery.
