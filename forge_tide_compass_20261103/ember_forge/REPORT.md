# Ember Forge

Created and reviewed in live Blender and the separate native Badge Studio preview. The final working checkpoint is candidate02.

[Reference comparison](candidate02/review/comparison.png) | [All sides](candidate02/review/all_sides.png) | [Slow turn](candidate02/review/full_turn.mp4).

Physical beveled hexagon, cut hammer and anvil, curled flame relief, wrapped handle and matching sculpted rear. Each front has a finished matching rear and continuous side walls. Existing badges and the production app are preserved.

The requested reference weathering and surface color are retained with reference appearance fill. Physical metal uses the measured native studio response, so live reflections and glints change during rotation. Any gemstone has independent closed convex geometry and the existing runtime optical shader, without photographed appearance textures. Emissive flame or atmospheric artwork remains distinct from gemstone optics.

Native front, early turn, both sides, back and full turn were visually checked, along with four times outline views and the reflection. ARKit USD validation and closed solid checks passed. 12340 triangles; 2.83 MB.

The deliberate reference texture is an exception to the generic smooth surface preference. The rendered highlights differ from a static illustration because the studio stays fixed while the object turns. The comparison records the actual current match.
