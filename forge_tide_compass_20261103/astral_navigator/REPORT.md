# Astral Navigator

Created and reviewed in live Blender and the separate native Badge Studio preview. The final working checkpoint is candidate03.

[Reference comparison](candidate03/review/comparison.png) | [All sides](candidate03/review/all_sides.png) | [Slow turn](candidate03/review/full_turn.mp4).

Concentric engraved gold dial, 180 physical scale marks, eight raised compass blades, reference traced scrolls and crescent ornaments, nine front Sapphire stones with nine matching reverse stones. Each is independently closed and convex with real crown and pavilion facets. Reference thin frame is local to this design and preserves all approved shared coin assets.. Each front has a finished matching rear and continuous side walls. Existing badges and the production app are preserved.

The requested reference weathering and surface color are retained with reference appearance fill. Physical metal uses the measured native studio response, so live reflections and glints change during rotation. Any gemstone has independent closed convex geometry and the existing runtime optical shader, without photographed appearance textures. Emissive flame or atmospheric artwork remains distinct from gemstone optics.

Native front, early turn, both sides, back and full turn were visually checked, along with four times outline views and the reflection. ARKit USD validation and closed solid checks passed. 88556 triangles; 4.82 MB.

The deliberate reference texture is an exception to the generic smooth surface preference. The rendered highlights differ from a static illustration because the studio stays fixed while the object turns. The comparison records the actual current match.

The file uses eighteen independent optical stones, nine visible on the front and nine matching stones on the reverse. Each has genuine crown and pavilion facets with no photographed appearance. The new private material `CrestGem_SapphireAstral` selects stronger intrinsic absorption for the deep blue reference. Its runtime integration is documented in [RUNTIME.md](RUNTIME.md) and [runtime_material.patch](runtime_material.patch). The USDZ alone contains only the ordinary deep blue fallback. Existing gemstone profiles, Diamond and studio lighting retain their previous values.

The 88,556 triangles exceed the usual target because the dial preserves 180 physical scale marks, 60 traced ornament components, detailed concentric settings and the front and reverse gemstone cuts. The final package remains under 5 MB. Real facets and reflections change under the fixed studio, so the round center cut and individual glints differ from the static cabochon illustration. The native comparison shows the actual current result.
