## One coordinated height source

Generate a single grayscale HEIGHT map using the built in image tool with the actual reference crop as style guidance. This is a scalar sculpt surface field, not a shaded picture or photograph. Black is the bottom of broad irregular incised grooves, pale gray is the flatter raised wood surface. No cast shadows, highlight direction, metal, color, plank borders or seams. Ask for 8 to12 substantial flowing groove channels across the plank height, several irregular branch cracks, a large rounded knot about a tenth of the full physical plank width with flowing surrounding grain. Avoid fine pores, shredded bark fibers, white speckles, uniform sine rings or generic noise. This is intrinsic wood structure for a real shader.
