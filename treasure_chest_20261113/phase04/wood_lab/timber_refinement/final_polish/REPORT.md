# Final wood polish

Starting checkpoint: Git 97cce9c, AW_depth_hierarchy/master.blend. The complete saved master, packed maps, numerical heights and reference are recoverable from that commit. checkpoint.json verifies the committed dependency bytes. Existing cleanup deletions and unrelated badge work were excluded.

## Controlled findings

The same Cycles camera, exposure, AgX look, sample seed, light positions and source sizes were reused. A specular removed diagnostic showed that pale pink highlights are partly a reflection response, not solely pigmentation. Removing specular is diagnostic only and is rejected as a final material. The intrinsic pigment is already dark wood, not a painted set of bright directional highlights.

AX tests a small linear pigment rebalance toward chestnut and burnt amber while retaining each texel's luminance. AY tests a roughness floor only on smoother existing patches. AZ tests one bounded shock step only at resolved broad grain transitions. BB tests width hierarchy only in the right bay. A separate warmer key test holds the material and geometry fixed. Actual comparison sheets were opened, including both bays.

The local roughness floor and warmer key do not add enough visual benefit to replace the established material response and lighting. They are rejected. The final combination retains the bounded transition correction, localized right bay hierarchy and restrained pigment adjustment. Roughness, IOR, normal strength, exposure and lights remain at AW values. No cracks, fibers, polygons or texture generation systems were added.

The transition correction is limited to roughly 0.0014 scene units and excludes the knot, major fracture masks and boundaries. Existing fine height remains, with complementary normals recomputed against the actual updated mesh. The right correction changes only the prominence of existing narrow channels; it does not copy the knot region or introduce another pattern. Full numerical fields remain editable.

The core relief and distinctive existing near vertical split are deliberately preserved. Earlier synthetic and traced core reconstructions had already regressed the natural appearance. This round changes its pigment with the coordinated material but does not add rings, deepen the center or outline it.

## Evidence and limits

Final review images are generated by present.py from the resolved PNGs beside BC_final_polish/master.blend. Context shaders and floor contact remain temporary in an isolated render process. No context material is transferred to live chest components.

Some broad formations still differ from the reference's sharper, more individually shaped ledges. The knot inner contour is an interpretation and does not exactly match the reference. Repeated isolated recoloring or sharpening would risk the successful foundation. Further whole chest tonal decisions are better made with finished surrounding iron, brass and wood. The owner reviews the test plank before any transfer.
