# Emerald Trophy matching gold rim

Candidate06 matches the rim finish to the trophy. The owner explicitly requested this material change, overriding the previous frozen rim finish for this trophy only. The rim now has warmer gold, smoother reflections, and fine intrinsic grain taken from a clean central area of the reference cup. Broad illumination was removed from that grain before it was applied. The selected gold is linear RGB 0.84, 0.45, 0.10, with band roughness 0.205 and outer wall roughness 0.195. The rim uses no emission or painted highlight bands. Its light and dark reflections remain produced by the original app studio.

All geometry, normals, UVs, recognized casing and material names, and complete traced crest data are exactly preserved from candidate05. The native material edit changes only the three rim diffuse color values and the two rim color and roughness PNG files. Every other packed texture byte is unchanged, including the field, crest detail and original border roughness maps. Compact inner glints, the outer border finish, runtime anisotropy and the app's coin glint shield are retained. The separate material audit is `candidate06/rim_validation.json`.

The complete working copy was inspected in live Blender at the front, back, both sides and an angle. Native simulator checks cover the front, back, both sides, full turn, reflection and four outline enlargements at 4x. No new broken outer outline, detached bright outer specks or external bloom puffs were observed in these checks. Apple's ARKit USD checker and the app contract checks pass, including complete field coverage, the closed circular shell, identity transforms, Y up meters, matching back, and no zero normals, degenerate triangles, cameras or lights.

The selected file is `mobile/emerald_trophy_badge_mobile.usdz`, with complete editable scene `emerald_trophy.blend`. `rim_comparison.jpg` compares the old and matched rim in the app, and `comparison.jpg` compares the current model with the original reference at equal outer diameters. The previous model and scene are preserved in `previous/`. The file is 10,666,268 bytes with 154,724 triangles, retaining the detailed double sided reference reconstruction from candidate05. This remains above the size and triangle guidelines for the same contour and relief detail reasons documented in the preserved candidate05 report. Physical device performance has not been measured. Floating placement remains size 0.96 and lift 0.56, with lowest world Y minus 2.455.

The private preview build succeeded with its existing FocusSessionManager unreachable code warning. The result is selected facing forward in Badge Studio on Badge Studio Preview, using the private `preview/ScreenTime.xcodeproj`, scheme `ScreenTime-UIOnly`. Production app code and assets were not written. Original studio lighting, camera, floor, reflection, glow and gem shader are unchanged. No commits or branch changes were made.
