Ruby Heart versions

Version 1 is mobile/ruby_heart_v1.usdz: the ruby before the latest gem work, with the approved smooth gold rim. Its preserved editable Blender source is ../ruby_heart_smooth_20261112/ruby_heart.blend.

Version 2 is mobile/ruby_heart_v2.usdz: the newer faceted ruby cut. Its editable Blender source is source/ruby_heart.blend. The gold geometry and finish are identical between versions.

mobile/ruby_heart.usdz remains a copy of Version 2, which is currently installed in the private simulator. Both named models are retained separately. Exact identities are recorded in versions.json.
